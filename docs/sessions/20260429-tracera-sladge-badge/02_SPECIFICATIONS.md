# Specifications

## Acceptance Criteria

- README badge block includes the Sladge badge.
- Badge links to `https://sladge.net`.
- No runtime, workflow, backend, frontend, or test files are modified.
- Session docs record the isolated-worktree reason.

## Out Of Scope

- Quality-gate workflow fixes.
- Agent implementation changes.
- Docs deployment changes.
- Runtime validation beyond docs-only checks.
