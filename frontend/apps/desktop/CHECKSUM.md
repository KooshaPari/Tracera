> NOTE: electron-builder currently bundles Electron's Chromium runtime DLLs
> (~80 MB overhead) because `electronVersion` is set to satisfy its sanity
> checks. End-state (per `feedback_no_script_launchers.md` and the WinUI-rs
> roadmap) is a native Rust installer via `cargo-dist` + WiX; this PR is the
> step-1 stopgap so a real installable .exe is shippable today.
